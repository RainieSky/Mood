映心情绪数字分身移动端网页

1. 直接打开 index.html 即可体验主要交互。
2. 若要在手机上稳定测试语音、PWA 与体感权限，请在同一局域网中启动本地服务器：
   在 Windows PowerShell 进入本文件夹，执行：
   python -m http.server 8080
   手机与电脑连接同一网络后，在手机浏览器打开电脑的局域网 IP 加端口 8080。
3. 触屏可拖动抚摸分身；呼吸页可选择节奏；轨迹页可生成并下载情绪卡。
4. 语音识别是否可用取决于浏览器和设备。无法识别时会进入演示流程。
5. 体感权限在“设置与说明”中开启，iOS 通常需要用户手势授权。
6. 当前原型没有后端，记录保存在浏览器 localStorage 中，不构成心理诊断。
7. 如需直接预览有互动记录的“轨迹”页面，可在地址后加 ?demo=1#journey。
